# Block 11: Interview Brief composition

The brief composes the existing evidence-grounded InterviewPreparation with one
InterviewRound, an optional CompanyProfile, optional public professional
interviewer context, and verified previous-round feedback. It does not create
answers, rewrite CandidateProfile, or perform research/provider calls.

Candidate and job scopes must agree. Company inclusion requires the selected
global company ID to match its snapshot. Company source signature, attributed
claims and uncertainties remain attached to the brief. Do not infer the company
ID from fuzzy names at this boundary.

Prior feedback must have a matching earlier round from the same candidate/job;
timestamps alone do not establish order. Current, future, unknown, or foreign
round feedback is rejected. A complete input signature changes when preparation,
round, company evidence, interviewer context or feedback changes.

Interviewer context supports only professional role, public trajectory,
expertise, and relationship to the vacancy. Research fields require public
provenance and must match the round's named interviewer or known role. A role
alone can remain without a name; it is not a researched biography. Private
provenance is rejected. No personal-life fields or personality inference exist.
Integrators must verify public source content; a URL is not semantic proof.

Developing/gap evidence is not promoted into strongest evidence. Existing caution
text survives in likely areas. Legacy preparation remains KEEP as the grounding
builder, not a competing answer generator. UI rendering, source resolution and
real browser/provider E2E remain integration work; this block is deterministic
composition only and has no database migration.
