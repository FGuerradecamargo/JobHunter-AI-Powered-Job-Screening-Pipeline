\# JobHunter



\## Vision



JobHunter is an engineering project that automates the entire job discovery workflow.



Instead of manually reading hundreds of job postings, the system will:



\- Read job alerts from Gmail

\- Extract structured job information

\- Compare jobs against my professional profile

\- Calculate a compatibility score

\- Present only high-value opportunities



The project is intentionally being developed incrementally, following real business needs instead of speculative architecture.



\---



\## Current Sprint



Sprint 2 — Gmail Alerts



Current Goal:



Receive LinkedIn job alerts and access them programmatically through the Gmail API.



No AI.

No database.

No parsing.



Only prove that we can reliably read job alerts.
